# رفيقك — الإصدار 2

تطبيق أندرويد يذكّرك بالطاعات في أوقاتها: الثلث الأخير، الجلوس بعد الفجر، أذكار المساء، الصيام، ساعة الجمعة والكهف، مع سلسلة مواظبة وسجل شهري.

## التشغيل
1. انسخ هذا المشروع فوق مستودعك القديم، ثم **احذف** الملفات القديمة التي لم تعد مستخدمة:
   `app/src/main/res/layout/` و`navigation/` و`menu/` و`raw/azkar.json` وكل ملفات `java/com/rafiqk/app/` القديمة (ما عدا الجديدة هنا).
2. خط Cairo العربي يُنزَّل تلقائيًا أثناء تشغيل GitHub Actions ويُضاف إلى التطبيق، ولا تحتاج إلى رفع ملف الخط يدويًا.
3. ملف `app/src/main/res/raw/takbir_short.mp3` اختياري: بدونه لا يُشغَّل صوت التكبير ولا يتعطل التطبيق. تأكد من ترخيص أي ملف صوتي تضيفه.
4. الأسرار في GitHub (اختيارية للتوقيع): `KEYSTORE_BASE64` و`STORE_PASSWORD` و`KEY_PASSWORD`، والـ alias هو `rafiqk`.
   بدونها يُبنى `debug` موقّعًا و`release` غير موقّع.
5. يبدأ البناء تلقائيًا عند رفع التعديلات إلى فرع `main` أو `master`، ويمكنك أيضًا تشغيله يدويًا من تبويب Actions عبر `Build APK`.

## ما تغيّر
- واجهة Jetpack Compose بتصميم جديد (عدّاد الصلاة القادمة، بطاقة الجلوس بعد الفجر، عدّاد أذكار بالضغط، تقويم شهري).
- الجدولة تغطي يومين متحركين وتتجدد بعد كل تنبيه وبعد منتصف الليل والإقلاع وتغيّر الوقت، فلا تتوقف بعد أول يوم.
- الثلث الأخير يُحسب لليلة التي تنتهي بفجر اليوم (كان يتداخل مع اليوم التالي).
- أيام الصيام: الاثنين والخميس والأيام البيض ورمضان، ويُستثنى العيدان وأيام التشريق.
- الأذان/التكبير عبر خدمة أمامية، مع زر إيقاف.
- مدن جاهزة (٤٣ مدينة) وتحديد بـ GPS بدل إدخال الإحداثيات يدويًا، مع احترام المنطقة الزمنية للمدينة.
- بيانات الأذكار صارت في `AzkarData.kt` (بلا Gson ولا JSON).

## قبل النشر
- راجع نصوص `AzkarData.kt` مع أهل العلم.
- أكمل نموذج Foreground Service (media playback) وبيانات الأمان في Google Play.
